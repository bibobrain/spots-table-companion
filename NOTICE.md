# Fan-made project notice

This free player aid is independently developed for the tabletop game **Spots**. It is **not affiliated with, endorsed by, or sponsored by** CMYK, BoardGameGeek or Board Game Arena.

The MIT license applies to original program code and custom interface artwork included in this repository. It does not license the Spots name, trademarks, original card illustrations, rulebook, or other third-party assets. No official card scans or rulebook PDF are distributed here.

The illustration atlases were created with AI image-generation assistance for this project. The twelve-pose Dalmatian atlas uses slender, spotted dogs and clean ink-style outlines to match the existing Action illustrations. These are original companion illustrations; no official card art was copied. The backyard, dice, and other vector interface artwork are also original to this project. Development used AI coding assistance.

The app uses `assets/dalmatian-poses.webp` for dog cards and `assets/puppy-actions.webp` for the existing Action artwork. The source PNGs remain in the public repository; offline releases include the WebP runtime copies and omit the source PNGs.

Gameplay instructions are independently written summaries. Consult the physical rulebook for authoritative rules. See [CMYK](https://www.cmyk.games/products/spots), [public rulebook](https://www.rulespal.com/spots/rulebook), and [BGG](https://boardgamegeek.com/boardgame/372559/spots).
